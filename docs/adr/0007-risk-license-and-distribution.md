# ADR 0007: Risk, licensing and distribution

Status: accepted (2026-09-12)

The project is MIT. HoneyBBQ is MIT; Effect, Solid and OpenTUI pins are recorded in manifests and lockfile. Upstream code with unresolved licensing is not copied. Source execution is the only distribution claim. Binaries, checksums, third-party notices, signing and GitHub releases wait for M5 target-native evidence. High risks are Effect RC churn and unverified HoneyBBQ/Bun networking; both are bounded behind package/port seams and truthful capability gates.
