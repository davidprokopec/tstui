# ADR 0008: Master branch and governance

Status: accepted (2026-09-12)

The user selected `master` as the default branch. Contributions use Conventional Commits and pull requests with intended required `ci`, linear history, and no force pushes or deletion. These remote policies are not applied or claimed in M0 because no GitHub automation is available. Release Please files are a foundation only; no tag, release or package publication occurred.
