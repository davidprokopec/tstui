# ADR 0002: TeamSpeak adapter

Status: accepted with capability gate (2026-09-12)

Pin `@honeybbq/teamspeak-client@0.2.3` behind `TeamSpeakPort`. It is a real client protocol implementation rather than ServerQuery, but declares Node support and is young. M0 verifies identity roundtrip, disconnected client initialization, normalization, and mock-only lifecycle behavior on Bun; it does not contact a server. Each connection has an explicit generation from identity setup through initial listing. Failure or interruption terminally projects disconnected, while manual or remote disconnect invalidates ownership so deferred stale work cannot publish state or report success. Adapter clients are acquired under a child Scope before connect, with one bounded dropping callback ingress and a separate terminal queue. Overflow is projected explicitly. Version 0.2.3 has no listener-removal API, so named callbacks are deactivated before scoped disconnect and the client/closures are released together; the project does not claim unregister support. Live connectivity and integrated reconnect stay gated to M1. ReSpeak IPC remains a possible fallback only after evidence shows it is needed. Voice and files are unavailable.
