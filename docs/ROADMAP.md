# Roadmap

- **M0 (implemented):** tested offline demo, ports/services/projection/commands, host-neutral TUI and standalone host.
- **M1 (in progress):** offline interactive client. Focus and channel-tree navigation/joining are implemented; composer, private tabs, help, and connect UX remain.
- **M2:** configuration, persistence and logging UX.
- **M3–M5:** authorized live-server compatibility, live text behavior, reconnect, permissions and hardening.
- **M6–M7:** isolated audio spike, then evidence-gated voice integration.
- **M8:** OpenCode v2 plugin against a newly verified pinned host API.
- **M9–M10:** platform evidence, target-native binary matrix, checksums, notices and releases.
