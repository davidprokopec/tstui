# Code of Conduct

We pledge to make participation harassment-free for everyone. Be respectful, assume good intent, accept constructive feedback, and focus on what is best for the community.

Unacceptable behavior includes harassment, discriminatory language, threats, sustained disruption, or publishing private information. Project maintainers may remove content or participation that violates these standards. Report conduct concerns privately using the contact route in [SECURITY.md](SECURITY.md).
